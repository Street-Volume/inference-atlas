M447 / M577 Homework 7 · Hillier and Lieberman, Section 4.7

Operations research: shadow prices and sensitivity

Five linear programs. Read off which constraints bind, price each resource by how much one more unit raises the optimum, and find how far the objective can tilt before the optimal corner changes.

Problems 1 and 2 · the two-resource model
OR1

Binding constraints and the price of a resource

HW7 · Problem 1
Problem

Maximize \(Z=x_1+2x_2\) subject to \(x_1+3x_2\le8\) (resource 1), \(x_1+x_2\le4\) (resource 2), \(x_1,x_2\ge0\). The optimal solution is \((x_1^*,x_2^*)=(2,2)\) with \(Z^*=6\).

(a) Is either constraint binding? (b) Use graphical analysis to find the shadow price of each resource. (c) How many additional units of resource 1 would raise the optimal value by 1.5?

From the textbook
Binding constraint
A constraint that holds with equality at the optimal solution. A nonbinding constraint has slack left over, so a little more of that resource changes nothing: its shadow price is 0.
Shadow price
\(\class{tb}{y_i^*=\dfrac{\Delta Z^*}{\Delta b_i}}\): the rate at which the optimal value rises per extra unit of resource \(i\), all else fixed. It holds while the same constraints stay binding (the allowable range).
Graphical method
Shift the resource's constraint line out by one unit, find the new corner where the binding lines cross, and measure the change in \(Z\).
Quant financeShadow prices from a linear program are the marginal value of one more unit of a constrained resource — in portfolio optimization this is literally the marginal utility of one more dollar of risk budget or capital, the number that tells a desk exactly how much performance it's giving up because of a capital constraint.

Solution

  1. (a) Plug the optimum into each constraint.

    \[ x_1+3x_2=2+3(2)=8=8,\qquad x_1+x_2=2+2=4=4 \]

    Both hold with equality, so \(\class{dv}{\text{both constraints are binding}}\).

  2. Keep the right-hand sides as symbols. The optimal corner is where the two binding lines cross, so solve them with \(b_1,b_2\) in place of 8 and 4.

    \[ x_1+3x_2=b_1,\qquad x_1+x_2=b_2 \]

    Subtract the second from the first: \(2x_2=b_1-b_2\), so \(x_2=\dfrac{b_1-b_2}{2}\). Then \(x_1=b_2-x_2=\dfrac{3b_2-b_1}{2}\).

  3. Write the optimal value as a function of the resources.

    \[ Z^*=x_1+2x_2=\frac{3b_2-b_1}{2}+(b_1-b_2)=\frac{3b_2-b_1+2b_1-2b_2}{2}=\frac{b_1+b_2}{2} \]

  4. (b) Read off the shadow prices. Shadow price Each extra unit of either resource adds one half to \(Z^*\).

    \[ \class{dv}{y_1^*=\tfrac12,\qquad y_2^*=\tfrac12} \]

    Graphical check: with \(b_1=9\) the corner moves to \((1.5,\,2.5)\) and \(Z=1.5+5=6.5\). With \(b_2=5\) it moves to \((3.5,\,1.5)\) and \(Z=3.5+3=6.5\). Both are \(+0.5\).

  5. Find how far \(b_1\) can move with the same binding pair (keep \(b_2=4\)). Both coordinates of the corner must stay nonnegative.

    \[ x_1=\frac{12-b_1}{2}\ge0\Rightarrow b_1\le12,\qquad x_2=\frac{b_1-4}{2}\ge0\Rightarrow b_1\ge4 \]

    So the shadow price \(\tfrac12\) holds for \(4\le b_1\le12\).

  6. (c) Solve for the extra units.

    \[ \Delta Z^*=y_1^*\,\Delta b_1\ \Longrightarrow\ 1.5=\tfrac12\,\Delta b_1\ \Longrightarrow\ \class{dv}{\Delta b_1=3} \]

    New \(b_1=11\) is inside \([4,12]\), so the shadow price still applies. Check: the corner becomes \((0.5,\,3.5)\) and \(Z=0.5+7=7.5=6+1.5\ \checkmark\)

Answer
(a)Both constraints are binding
(b)\(y_1^*=\) 0.5, \(y_2^*=\) 0.5
(c)3 additional units of resource 1
OR2

How far can the objective tilt?

HW7 · Problem 2
Problem

Same constraints as OR1. Use sensitivity analysis on the objective coefficients. (a) If \(Z=21x_1+60x_2\), does \((2,2)\) stay optimal? (b) If \(Z=11x_1+10x_2\)? (c) With \(c_1=1\) fixed, what range of \(c_2\) keeps \((2,2)\) optimal? (d) With \(c_2=2\) fixed, what range of \(c_1\)?

From the textbook
Slope test for a corner
The iso-profit line \(c_1x_1+c_2x_2=Z\) has slope \(\class{tb}{-c_1/c_2}\). A corner stays optimal while that slope stays between the slopes of the two constraint lines that meet there.
Same test, as a cone
Equivalently, \((c_1,c_2)\) must lie between the normal vectors of the two binding constraints. Live figure C2 draws that cone.
Quant financeAsking how far objective coefficients can move before the optimal corner changes is objective-sensitivity analysis — in a mean-variance portfolio, it tells you how wrong your expected-return forecasts can be before the optimizer would have picked a different portfolio, exactly the robustness check real portfolio construction needs.

Solution

  1. Slopes of the binding lines at \((2,2)\).

    \[ x_1+3x_2=8\ \Rightarrow\ x_2=\tfrac83-\tfrac13x_1\ (\text{slope }-\tfrac13),\qquad x_1+x_2=4\ \Rightarrow\ \text{slope }-1 \]

  2. Optimality condition. Slope test With \(c_2\gt0\):

    \[ -1\le-\frac{c_1}{c_2}\le-\frac13\quad\Longleftrightarrow\quad\class{dv}{\frac13\le\frac{c_1}{c_2}\le1} \]

    Current objective: \(c_1/c_2=1/2\), inside the range, which is why \((2,2)\) is optimal now.

  3. (a) \(c_1/c_2=21/60=0.35\). Since \(0.333\le0.35\le1\), \(\class{dv}{\text{yes, }(2,2)\text{ stays optimal}}\).

    Check the corners: \((2,2)\to162\), \((0,\tfrac83)\to160\), \((4,0)\to84\). Close, but \((2,2)\) wins.

  4. (b) \(c_1/c_2=11/10=1.1\gt1\). \(\class{dv}{\text{No.}}\) The new optimum is \((4,0)\): \(Z=44\) beats \((2,2)\)'s 42.

  5. (c) Set \(c_1=1\): \(\tfrac13\le\tfrac1{c_2}\le1\). Taking reciprocals of positive numbers flips the inequalities:

    \[ \class{dv}{1\le c_2\le3} \]

  6. (d) Set \(c_2=2\): \(\tfrac13\le\tfrac{c_1}{2}\le1\). Multiply by 2:

    \[ \class{dv}{\tfrac23\le c_1\le2} \]

    At an endpoint the iso-profit line lies flat along an edge, so a second corner ties; \((2,2)\) is still optimal, which is why the endpoints are included.

Answer
(a)Yes (ratio 0.35 is in [1/3, 1])
(b)No (ratio 1.1; new optimum (4, 0))
(c)1 ≤ c₂ ≤ 3
(d)2/3 ≤ c₁ ≤ 2
Problems 3 and 4 · the three-resource model
OR3

Three resources, one with slack

HW7 · Problem 3
Problem

Maximize \(Z=3x_1+2x_2\) subject to \(x_1\le4\) (resource 1), \(x_1+3x_2\le15\) (resource 2), \(2x_1+x_2\le10\) (resource 3), \(x_1,x_2\ge0\). The optimal solution is \((3,4)\) with \(Z^*=17\).

(a) Which constraints are binding? (b) Use graphical analysis to find the shadow prices.

From the textbook
Nonbinding means a zero price
\(\class{tb}{\text{slack}_i\gt0\ \Rightarrow\ y_i^*=0}\). Small changes to that resource leave the optimal corner where it is.
Shadow price
\(\class{tb}{y_i^*=\Delta Z^*/\Delta b_i}\) within the allowable range, found by re-solving the binding system with \(b_i\) as a symbol.
Quant financeA resource with slack (shadow price zero) is a constraint that isn't actually binding — recognizing this is how a portfolio manager knows which risk or capital limits are truly constraining the portfolio versus which ones have headroom and don't matter yet.

Solution

  1. (a) Plug \((3,4)\) into each constraint.

    \[ x_1=3\lt4\ (\text{slack }1),\qquad x_1+3x_2=3+12=15,\qquad 2x_1+x_2=6+4=10 \]

    \(\class{dv}{\text{Resources 2 and 3 are binding; resource 1 is not.}}\)

  2. Resource 1. It has one unused unit, so \(\class{dv}{y_1^*=0}\).

  3. Solve the binding pair with symbols.

    \[ x_1+3x_2=b_2,\qquad 2x_1+x_2=b_3 \]

    From the second, \(x_2=b_3-2x_1\). Substitute: \(x_1+3b_3-6x_1=b_2\), so \(x_1=\dfrac{3b_3-b_2}{5}\) and \(x_2=b_3-2x_1=\dfrac{2b_2-b_3}{5}\).

  4. Optimal value as a function of \(b_2,b_3\).

    \[ Z^*=3x_1+2x_2=\frac{9b_3-3b_2+4b_2-2b_3}{5}=\frac{b_2+7b_3}{5} \] \[ \class{dv}{y_2^*=\tfrac15=0.2,\qquad y_3^*=\tfrac75=1.4} \]

  5. Graphical check. \(b_2=16\): corner \((2.8,\,4.4)\), \(Z=8.4+8.8=17.2\), up 0.2. \(b_3=11\): corner \((3.6,\,3.8)\), \(Z=10.8+7.6=18.4\), up 1.4, and \(x_1=3.6\le4\) still holds.

    The statement lists \(x_3\ge0\), but this problem has no \(x_3\). It's a typo; ignore it.

Answer
(a)Resources 2 and 3 binding; resource 1 not binding
(b)\(y_1^*=\) 0, \(y_2^*=\) 0.2, \(y_3^*=\) 1.4
OR4

Which corner wins for every objective

HW7 · Problem 4
Problem

Same constraints as OR3, with objective \(Z=c_1x_1+c_2x_2\), \(c_1,c_2\ge0\). Find the range of \(c_1/c_2\) that keeps each point optimal: (a) \((3,4)\), (b) \((4,2)\), (c) \((0,5)\). (d) If \(c_1,c_2\) may be negative, find the conditions on \(c_1,c_2\) and the range of \(c_1/c_2\) that keep \((4,0)\) optimal.

From the textbook
Slope test at each corner
Corner optimal \(\Leftrightarrow\) \(\class{tb}{-c_1/c_2}\) lies between the slopes of the two lines that meet there.
Cone test (works for any signs)
Write each constraint as \(a_1x_1+a_2x_2\le b\), so \(x_1\ge0\) becomes \(-x_1\le0\). A corner is optimal \(\Leftrightarrow\) \((c_1,c_2)\) is a nonnegative combination of the normals \((a_1,a_2)\) of the constraints active there.
Quant financeMapping which vertex is optimal across a whole range of objective directions is exactly how an efficient frontier is built: each vertex of the feasible region is optimal for some range of risk-aversion levels, the same way a corner point here is optimal for a range of cost ratios.

Solution

  1. List the corners and the lines meeting at each. Going around the region: \((0,0)\), \((4,0)\), \((4,2)\), \((3,4)\), \((0,5)\).

    \((4,2)\): \(x_1=4\) (vertical) and \(2x_1+x_2=10\) (slope \(-2\)). \((3,4)\): slope \(-2\) and \(x_1+3x_2=15\) (slope \(-\tfrac13\)). \((0,5)\): slope \(-\tfrac13\) and \(x_1=0\) (vertical).

  2. (a) \((3,4)\). Objective slope between \(-2\) and \(-\tfrac13\):

    \[ -2\le-\frac{c_1}{c_2}\le-\frac13\ \Longleftrightarrow\ \class{dv}{\frac13\le\frac{c_1}{c_2}\le2} \]

    The original \(Z=3x_1+2x_2\) has ratio 1.5, inside, consistent with \((3,4)\) being optimal.

  3. (b) \((4,2)\). Slope between vertical and \(-2\), so steeper than \(-2\):

    \[ -\frac{c_1}{c_2}\le-2\ \Longleftrightarrow\ \class{dv}{\frac{c_1}{c_2}\ge2} \]

    If \(c_2=0\) the ratio is undefined; then the whole edge \(x_1=4\) is optimal, so \((4,2)\) still is, tied with \((4,0)\).

  4. (c) \((0,5)\). Slope between \(-\tfrac13\) and 0 (with \(c_1\ge0\)):

    \[ -\frac13\le-\frac{c_1}{c_2}\le0\ \Longleftrightarrow\ \class{dv}{0\le\frac{c_1}{c_2}\le\frac13} \]

  5. (d) \((4,0)\) with any signs. Cone test Active constraints there: \(x_1\le4\) with normal \((1,0)\), and \(x_2\ge0\), written \(-x_2\le0\), with normal \((0,-1)\).

    \[ (c_1,c_2)=\lambda(1,0)+\mu(0,-1)=(\lambda,-\mu),\ \lambda,\mu\ge0\ \Longrightarrow\ \class{dv}{c_1\ge0,\ c_2\le0} \]

    For \(c_2\lt0\) that gives \(\class{dv}{c_1/c_2\le0}\).

  6. Why the ratio alone isn't enough in (d). \(c_1/c_2\le0\) also holds for \(c_1=-1,\ c_2=1\), but then \(Z=-x_1+x_2\) is maximized at \((0,5)\), not \((4,0)\). The signs carry information the ratio throws away.

    Check with \(c=(1,-1)\): corners give \(0,\ 4,\ 2,\ -1,\ -5\), so \((4,0)\) wins.

Answer
(a)1/3 ≤ c₁/c₂ ≤ 2
(b)c₁/c₂ ≥ 2
(c)0 ≤ c₁/c₂ ≤ 1/3
(d)c₁ ≥ 0 and c₂ ≤ 0 (not both 0); for c₂ < 0, c₁/c₂ ≤ 0
Problem 5 · reading the simplex tableau
OR5

Shadow prices from the final tableau

HW7 · Problem 5
Problem

Maximize \(Z=2x_1-x_2+x_3\) subject to \(3x_1+x_2+x_3\le6\) (resource 1), \(x_1-x_2+2x_3\le1\) (resource 2), \(x_1+x_2-x_3\le2\) (resource 3), \(x_1,x_2,x_3\ge0\). The final simplex tableau is:

BasicEqZx₁x₂x₃x₄x₅x₆RHS
Z01001.501.50.52.5
x₄100011−1−21
x₁20100.500.50.51.5
x₂3001−1.50−0.50.50.5

(a) What is the shadow price of each resource? (b) If every capacity could be increased, which resource has priority? (c) Z is profit in millions, and one more unit of any resource costs $1 million. Should you buy one more unit of resource 1? Resource 2? Resource 3?

From the textbook
Shadow prices in the final tableau
With slack variables \(x_4,x_5,x_6\) added to constraints 1, 2, 3: \(\class{tb}{y_i^*=\text{coefficient of slack }i\text{ in row 0}}\).
Allowable range for \(b_i\)
The slack columns of the final tableau form \(B^{-1}\). Changing \(b_i\) by \(\Delta\) changes the basic variables to \(\class{tb}{x_B+\Delta\cdot(\text{column of slack }i)}\). The shadow price holds while all of them stay \(\ge0\).
Quant financeReading shadow prices and their allowable ranges straight off the final simplex tableau is how a risk desk gets both the price of relaxing a limit and the range over which that price stays valid — beyond the allowable range the whole optimal portfolio restructures, not just its P&L.

Solution

  1. Match slacks to resources. \(x_4\) is the slack of resource 1, \(x_5\) of resource 2, \(x_6\) of resource 3.

  2. (a) Read row 0 under the slack columns. Final tableau rule

    \[ \class{dv}{y_1^*=0,\qquad y_2^*=1.5,\qquad y_3^*=0.5} \]

    Consistency: \(x_4=1\) is basic, so resource 1 has one unused unit, which is exactly why its price is 0.

  3. Cross-check against the original problem. The tableau's solution is \(x_1=1.5,\ x_2=0.5,\ x_3=0\):

    \[ Z=2(1.5)-0.5+0=2.5,\qquad 3(1.5)+0.5=5\le6,\qquad 1.5-0.5=1,\qquad 1.5+0.5=2 \]

    Dual check: \(6y_1^*+1y_2^*+2y_3^*=0+1.5+1=2.5=Z^*\ \checkmark\)

  4. (b) Priority. The largest shadow price wins: \(\class{dv}{\text{resource 2}}\), worth 1.5 per unit, three times resource 3.

  5. Allowable ranges. Current \(x_B=(x_4,x_1,x_2)=(1,\,1.5,\,0.5)\). Slack columns: \(x_5\to(-1,\,0.5,\,-0.5)\), \(x_6\to(-2,\,0.5,\,0.5)\).

    \[ b_2+\Delta:\ (1-\Delta,\ 1.5+0.5\Delta,\ 0.5-0.5\Delta)\ge0\ \Rightarrow\ -3\le\Delta\le1 \] \[ b_3+\Delta:\ (1-2\Delta,\ 1.5+0.5\Delta,\ 0.5+0.5\Delta)\ge0\ \Rightarrow\ -1\le\Delta\le0.5 \]

  6. (c) Compare each price with the $1 million cost.

    Resource 1: \(0\lt1\). \(\class{dv}{\text{Don't buy}}\); it already has an unused unit.

    Resource 2: \(1.5\gt1\), and \(\Delta=1\) is inside \([-3,1]\). \(\class{dv}{\text{Buy}}\): net gain \(1.5-1=0.5\) million. The new optimum is \((2,0,0)\) with \(Z=4\).

    Resource 3: \(0.5\lt1\). \(\class{dv}{\text{Don't buy}}\). It's worse than it looks: \(\Delta=1\) is past the allowable 0.5, so the real gain is only 0.25 (\(Z\) goes to 2.75), a net loss of 0.75 million.

    Live figure C5 shows all three. Inside the allowable range \(Z^*\) follows the shadow-price line exactly; past it, the curve bends down.

Answer
(a)\(y_1^*=\) 0, \(y_2^*=\) 1.5, \(y_3^*=\) 0.5
(b)Resource 2
(c)Resource 1: no · Resource 2: yes, +0.5 million · Resource 3: no
