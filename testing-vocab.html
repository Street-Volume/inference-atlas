Hypothesis testing: the core vocabulary

Wackerly, Mendenhall & Scheaffer §10.2. The vocabulary behind 10.5, built from scratch.

The four elements of a test
1. Null hypothesis H₀
The claim being tested.
2. Alternative hypothesis Hₐ
What we conclude if we reject H₀.
3. Test statistic
A function of the sample used to make the decision.
4. Rejection region (RR)
The values of the test statistic for which H₀ is rejected.

In 10.5: \(H_0\!:\theta=0\); \(H_a\!:\theta\gt0\); Test 1 uses \(Y_1\) with RR \(\{Y_1\gt0.95\}\); Test 2 uses \(Y_1+Y_2\) with RR \(\{Y_1+Y_2\gt c\}\). A test is a decision rule fixed before looking at the data. Because \(H_a\) says θ > 0, which shifts the interval \((\theta,\theta+1)\) to the right, large observations are evidence against \(H_0\) — that's why both rejection regions have the form "statistic is large."

Smoke alarmA Type I error is a false alarm (it rings with no fire). A Type II error is a missed fire (no ring when there is a fire). α is the false-alarm rate. Making the alarm more sensitive cuts missed fires but raises false alarms — the two errors trade off.
Computing α, in three moves

1. Assume H₀ is true. If H₀ names a single value (a simple hypothesis), plug it in. 2. Find the distribution of the test statistic under that value. 3. Find the probability that the statistic lands in the rejection region.

Why tests are compared at the same α

Any test can be made to catch more true alternatives (smaller β) simply by rejecting more often — but that also raises α. So it's only fair to compare two tests after making their false-alarm rates equal. Then the better test is the one with larger power (smaller β) at the alternatives you care about. 10.5 does the first half of that job: find the \(c\) that puts Test 2 at the same α as Test 1. See Live figure B8 for the second half — comparing the two tests' power curves.

Power\(\text{power}(\theta)=P(\text{reject }H_0\mid\theta)\). For θ in \(H_a\), power \(=1-\beta(\theta)\). At the null value, power \(=\alpha\).
Textbook: Wackerly, Mendenhall and Scheaffer, Mathematical Statistics with Applications, 7th ed. (Cengage); Hillier and Lieberman, Introduction to Operations Research, 10th ed. (McGraw Hill).
